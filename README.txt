BUILD WITHOUT INSTALLING ANYTHING (GitHub):
1. Make a free account at github.com, click New repository (any name), then "uploading an existing file".
2. Unzip this project, drag ALL files/folders in (including the hidden .github folder), commit.
3. Open the Actions tab -> wait for the green check -> open the run -> download "chatanswer-mod".
4. Unzip it. Use the jar WITHOUT "-sources" in its name.
5. Put it in .minecraft/mods with Fabric Loader 0.18+ and Fabric API for 1.21.11.
